# VDT Apps Website

Free static website designed for GitHub Pages.

## Before publishing
1. Replace `YOUR-EMAIL@example.com` in `contact/index.html`.
2. Replace placeholder app descriptions/details as needed.
3. Add real app download/Google Play links when each app is published.
4. Review the Privacy Policy for each app's actual data practices.

## GitHub Pages
Upload these files to a GitHub repository and enable Pages from the repository's Settings > Pages, using the main branch and root folder.
